# スラッグ生成規則（確定）

## 方針

日本語タイトルからの自動ローマ字変換は行わない。**管理者が手入力**する。

## 入力UI

- 記事作成・編集フォームに`slug`の入力欄を用意（タイトルとは別項目）
- 入力時に簡易整形を自動で行う（大文字→小文字、スペース/アンダースコアをハイフンに変換）が、最終的な値はいつでも手で編集可能

## バリデーション

- 正規表現: `^[a-z0-9-]+$`（半角英数字とハイフンのみ）
- `posts.slug`のunique制約違反（重複）は422エラー
- 作成時・更新時のどちらでも同じ規則を適用

## 更新時の挙動

- 作成後もslugは編集可能
- 更新で値が変わった場合、該当レコードの`slug`カラムを更新するだけ（DB管理なのでファイル操作は不要。[docs/api/admin.md](../api/admin.md)参照）
